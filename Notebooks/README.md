# Notebooks

Our own notebooks for the competition, versioned with the repository.

- Generators and tools live as Python modules elsewhere in the repo; notebooks call them, so the same
  code runs locally (WSL) and on Kaggle.
- A notebook that reuses a public circuit pins it by SHA-256 and credits its author, source URL and
  license (Apache-2.0 NOTICE carried verbatim).
- Clear large outputs before committing.
