## What was done

Ran the unmodified official verifiers (WSL venv `~/venvs/gqai`, Python 3.14, kickmix 1.0.0 from PyPI)
on the circuits rebuilt in S1.4:

- dfthcsos: default salt.
- invsqrt: **reduced run** (`--shots-per-x 1 --batch-size 12`, all 3,133,452 inputs once). The full
  run (64 shots per input, about 1 h) was started, then stopped: the generator's own exact proof
  (S1.4) already covers every input and every HMR transcript, and the reduced run gives the cost.
  The full run remains mandatory before a submission is chosen as final.
- dqi: 8 salts (default, `private-1` … `private-7`, the names alex chilton uses), `--max-workers 2`.

## Why

Establish our baseline costs and the dqi failure spread across salts before the first submission.
