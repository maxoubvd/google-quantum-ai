## What was done

`tools/gate.py {invsqrt,dqi,dfthcsos,all} PATH [--salts N] [--official] [--proof-tree TREE]`:

- invsqrt: kickmix-engine full verification at the default salt and N − 1 extra salts (`private-1`…);
  optional exact full-domain proof with Syed Asad Ali's `prove_any.py` run from a relocated build tree (every x,
  every HMR transcript; valid for that generator family, whose frozen integer phase model it checks); optional
  official verifier.
- dqi: kickmix-engine on N salts; value/phase errors per salt, mean (expected) and worst cost; optional official
  verifier.
- dfthcsos: official verifier (the engine gives no speed-up there).
- all: the three, `tools/package.py --check-only`, and the projected score (dqi at its mean and at its worst).
- Cache: one JSON per (task, file SHA-256, salt, tool, tool version) in `~/work/gate-cache/`; only definite
  verdicts are cached. Exit code 0 only if everything passes.

## Why

M2.1: every later milestone needs one trustworthy, fast command that says "PASS, this cost, this failure
spread" before a candidate goes further; the cache avoids paying twice for the same circuit and salt.
