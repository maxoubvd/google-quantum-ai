## What was done

The user asked to start Phase 2 and to make at least one improved submission before 20 Nov (the milestone
date), ideally finishing Phase 2 by the evening of 19 Nov. The whole of Phase 2 does not fit in 32 hours (its
research effort estimates exceed 100 h), so the plan now has a Sprint 2a: the three "back to the frontier"
milestones run in parallel, one subagent per task, each in its own working copy (`generators/<task>/`;
`third_party/` stays pristine), builds and gates in WSL, deadline 2026-11-19 14:00 UTC; the main session
integrates, runs the official gates, packages, and the user submits by 17:00 UTC.

Each agent follows `CLAUDE.md` (no git, English, changelog entries, exactness), keeps a `WORKLOG.md` saved after
every sub-step, puts gated candidates in `artifacts/candidates/<task>-<tag>/` with a `RESULT.json`, and leaves
`PLAN.md`, `IDEAS.md` and `LEDGER.md` to the main session. No git worktrees: the agents need git-ignored data
(`artifacts/`, `downloads/`), and each owns a separate folder.

## Why

User request; parallel tracks are the only way to fit three milestones into one and a half days.
